# Prediksi Penjualan UMKM

Aplikasi Streamlit untuk memprediksi penjualan bulanan dengan Regresi Linear (scikit-learn).

Fitur: ringkasan & tabel prediksi lengkap, kisaran perkiraan, skenario (pesimis/normal/optimis),
simulasi promo, estimasi laba, perbandingan model, laporan otomatis, 4 tema warna.

Jalankan lokal: `pip install -r requirements.txt` lalu `streamlit run app.py`
